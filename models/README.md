# Trained models

Place the trained models in this folder if you want to keep them separate from the notebook.

Required models for the local application:

- `emotion_model.keras`
- `age_gender_model_finetuned.keras`

The original `age_gender_model.keras` is the pre-fine-tuning model. It is useful for comparison, but the local application uses the fine-tuned model.

If the model files are too large for normal GitHub uploads, keep them out of the repository and host them through a model/file service such as Hugging Face Hub, or use Git LFS.
